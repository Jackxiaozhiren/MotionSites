# MotionSites launch checklist

1. Merge the reviewed PR, enable GitHub Pages and confirm that the gallery loads.
2. Update About description, Topics, Website and Social Preview from repository Settings.
3. Capture real screenshots/GIFs of the strongest projects; ensure actual functionality and rights before sharing.
4. Share informative demos and short breakdowns in relevant frontend communities, respecting community rules.
5. Track legitimate stars, gallery visits and issues, and prioritize feedback. Avoid star-for-star exchanges or fabricated claims.

## Social preview process

Use the original `assets/motionsites-social-card.svg` design. A successful **Browser Smoke and Featured Demo Builds** job uploads a JPG artifact (1280×640, under 1 MB) to use in **GitHub repository Settings → Social preview**. This manual GitHub setting is distinct from the automatically generated Pages Open Graph JPG. The brand illustration does not imply that the pictured shapes are real website screenshots.
